About

I'm Max Penet, a software engineer based near Geneva, Switzerland, with over two decades of experience building software across the full product lifecycle.

I've been writing Clojure professionally for more than 15 years. These days I work at Exoscale, a European, privacy-focused cloud provider, where I use Clojure daily to help build and operate large-scale cloud infrastructure.

Most of my free time goes into open source. A few of the libraries I maintain:

  • spandex - Elasticsearch client
  • alia - Cassandra client
  • tape - Chronicle Queue library
  • hirundo and enso - Ring server adapters
  • legba - OpenAPI services
  • coax - clojure.spec coercion

More on GitHub. I was a DataStax MVP for Apache Cassandra in 2015, for work on Cassandra drivers and community support.

This blog is mostly about Clojure, the JVM, performance, and whatever else I happen to be digging into. You can find me on Bluesky.
